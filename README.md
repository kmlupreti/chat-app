# chat-app
> this is a simple cli based chat app implemented for learning async rust in [Programming in rust 2nd edition](https://www.oreilly.com/library/view/programming-rust-2nd/9781492052586/) book.
> I have implemented each section by first trying my own implementation and then only modifying it by comparing with implementation from book instead of simply copy-pasting.

## libraries used
* async_std
* tokio
* serde_json

## Running
### for client
`cargo run --bin client <ip:port>`
### for server
`cargo run --bin server <ip:port>`
